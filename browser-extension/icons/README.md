# TypeWise AI Extension Icons

This directory should contain icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## Creating Icons

You can create these icons using any graphic design tool. The icons should:

1. Represent the TypeWise AI brand
2. Be clear and recognizable at all sizes
3. Follow Chrome extension icon guidelines
4. Use a purple/blue gradient theme to match the app design

## Temporary Solution

For development and testing, you can use placeholder icons or copy them from the Mac app assets if available.
